A playable release, not a platform promise

Station Zero v0.1.0-alpha.1 is the first source-playable Ordivon Game release. It is a bounded developer Alpha: one deterministic mission, one verified player journey, exact replay, evidence-linked diagnosis, immutable deployment, same-Case comparison, reload recovery, and an archive that can be unpacked and reverified from clean state.

The release unit is not a screenshot or a successful local database. It is one exact source tree, one evaluated-input set, one archive digest, and one journey another machine can reproduce.

The player loop

The release journey is intentionally narrow:

  1. Create or open a deployment.
  2. Run the Station Zero mission through verified Team Ticks.
  3. Reach a terminal victory or failure.
  4. Move to an earlier World revision and inspect exact state.
  5. Open diagnosis and follow evidence-linked claims.
  6. Clone the deployment.
  7. Change one bounded coordination profile.
  8. Run again and compare inputs and outcomes.
  9. Reload the browser and recover the same Run.

The product surface stays small: Mission, Replay, Diagnosis, Compare, and Deploy Again. Raw Commands, logs, internal identifiers, engineering receipts, and earlier milestone controls remain behind the explicit debug surface.

One input changed the terminal outcome

Both retained Runs use the same power-constrained Scenario Case. The only evaluated-input difference is coordinationProfileId.

Replay and diagnosis are release features

The victory Run contains 19 point-in-time frames, 380 evidence nodes, 736 evidence edges, and 12 bounded key turns. The failure Run contains 22 frames, 443 nodes, 859 edges, and the same 12-key-turn cap.

Diagnosis does not ask a model to invent causality. Claims carry one of four evidence classes:

verified directverified contributorcounterfactual sensitivecontext only

A verified contributor is not promoted to the unique cause. Counterfactual sensitivity is a bounded one-step legal-alternative test, not a statistical causal estimate. Evaluation timeout is not relabelled as a mission failure. Raw Context and Artifact bodies remain behind detail APIs rather than inflating every frame.

The clean verification contract installs from the frozen lockfile, runs the complete check and Chromium journey, rebuilds receipts and measurements, and revalidates evaluated inputs. The tag workflow builds and uploads the same bytes it verifies. SHA256SUMS covers every uploaded evidence file except itself.

What the Alpha proves

  • A deterministic World and persistent multi-Agent Host can support a small player product rather than only an engineering harness.
  • Replay, diagnosis, comparison, and reload recovery can be release-critical instead of optional debugging tools.
  • One coordination-only input can be changed and compared without silently changing the Scenario or ruleset.
  • Fixture cognition can keep release verification deterministic while live Codex and Hermes remain optional experimental paths.
  • A source release can preserve identity beyond a Git tag through tree, evaluated-input, archive, and release digests.

What the Alpha does not prove

The Alpha does not establish that multi-Agent architecture is superior to an equal-budget single Agent. It does not claim that Codex or Hermes will complete every Scenario. It does not provide hosting, accounts, multiplayer, 3D, modding, a generic game platform, or a stable public compatibility promise.

The release-critical path uses deterministic Fixture cognition. That is deliberate: a downloadable release should not fail because a remote model is unavailable, expensive, changed, or rate-limited. Live Provider trajectories remain research evidence, not a prerequisite for opening the game.

The next game question

The strongest next experiment is not more presentation. It is the equal-budget single-Agent versus multi-Agent ablation already required by the Game research dossier. The same World, information budget, Tool access, action budget, and player surface must compare whether persistent specialists, typed communication, and explicit authority create capability that a strong classical or single-Agent baseline cannot reproduce economically.

Station Zero is small by design. Its value is that every visible outcome can be replayed, inspected, compared, and tied back to the exact release that produced it.
