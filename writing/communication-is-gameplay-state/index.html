Communication Is Gameplay State

The same typed task offer produced victory when delivered locally and power exhaustion when a disabled radio delayed it beyond the coordination window.

Publication brief

What to retain from this argument.

  1. The same task offer produced different outcomes when reachability changed.
  2. Messages need identity, delivery state, and World-conditioned timing rather than decorative logs.
  3. Delayed communication can consume an irreversible coordination window.
Scope and limitations
  • The result comes from one bounded Station Zero comparison.
  • It does not establish multi-agent superiority or a universal communication protocol.

A message becomes part of the World when the recipient may not receive it before the action window closes—and the lost time cannot be repaired by showing the text later.

The same message produced two Worlds

Station Zero evaluated the same typed task-offer under two communication conditions. When the Actors shared a local channel, the assignment was delivered immediately and the Team reached verified victory at Tick 18. When the station radio was unavailable, the message remained pending until communications recovered. The Team exhausted power at Tick 20.

Communication is gameplay state when reachability changes which information can arrive before an action window closes.

A message needs more than text

A persistent Agent communication object needs identity, sender, recipient, channel, creation time, delivery condition, status, and relation to Tasks or Proposals. The content can be identical while the operational meaning differs because one recipient has not yet received it.

A shared transcript would erase the distinction. It would make information globally visible even when the World says the channel is unavailable. Decorative chat bubbles would preserve the wording but not the causal constraint.

Reachability creates coordination windows

Communication can be:

  • delivered now;
  • pending on a World condition;
  • expired after a useful window;
  • rejected by authority or policy;
  • visible only to one Actor;
  • superseded by newer verified information.

These states influence which Tasks are ready and which Proposals are reasonable. A delayed task offer can be perfectly correct and still arrive too late to change the outcome.

The World remains authoritative

The Host stores Message identity and delivery status. The World determines whether the current channel condition permits delivery. The model cannot declare that a radio message arrived because it would be useful. Verification must bind the delivery transition to current World state.

This separation also supports recovery. After process replacement, the Host can determine which Messages were delivered, which remain pending, and which coordination window has already closed without replaying a conversation.

Communication does not prove multi-Agent superiority

The experiment proves that communication reachability can materially change one multi-Agent trajectory. It does not prove that three Agents outperform one Agent, that natural-language negotiation is necessary, or that a general society layer should exist.

A strong single-Agent or classical baseline may reproduce the same outcome with direct access to all information. That comparison remains part of the Game dossier's next falsifier.

A message becomes part of the game when the World can delay it, the recipient can act without it, and the lost time cannot be reconstructed from text alone.
